LoadHog Documentation

Everything you need to know about running LoadHog at your drop zone. If you can't find what you're looking for email us at loadhogmanifest@gmail.com

License Activation

When you subscribe to LoadHog you will receive a license key by email. It looks like this:

LH-XXXX-XXXX-XXXX

Enter this key the first time you open the Licensed version of LoadHog. The app will verify it and open normally. Your key is stored on your computer so you only need to enter it once.

Offline use: LoadHog works offline for up to 7 days after the last successful verification. After 7 days an internet connection is needed to verify your license.
Lost your key? Email loadhogmanifest@gmail.com and we will resend it.

Installation

  1. Download the LoadHog folder from the link in your welcome email
  2. Copy the folder to your DZ computer — anywhere works, Program Files, Desktop, Documents
  3. Open the folder and double click setup.bat
  4. A LoadHog shortcut appears on your desktop with the icon
  5. The folder hides itself automatically
  6. Double click the desktop shortcut to open LoadHog
No installation wizard needed. LoadHog is a single exe file with everything bundled inside. No Python, no dependencies, no admin rights required.

First Time Setup

Takes about 15 minutes. Do this before your first jump day.

  1. Click Admin in the top right — default PIN is 1234
  2. Go to Settings — change your club name, color, and admin PIN
  3. Go to Pilots — add your pilots and set their credit per load rate
  4. Go to Aircraft — confirm your aircraft and capacity
  5. Go to Ticket Types — set your ticket prices and instructor credit amounts
  6. Go to Club Gear — add your tandem and student rigs
  7. Go to Members — add your members with gear and waivers

Creating Loads

  1. Click Loads in the navigation bar
  2. Click + New Load — the default aircraft is pre-selected
  3. Assign a pilot from the dropdown and click Set
  4. The pilot is automatically credited their per-load rate
You cannot add jumpers until a pilot is assigned.

Adding Jumpers

  1. Type the jumper's name in the search box
  2. Click their name in the dropdown
  3. Select their ticket type
  4. Click + Add

Their account is debited automatically. Common errors:

  • No waiver on file — log a waiver on their profile first
  • No pilot assigned — assign a pilot to the load first
  • Load full — plane is at capacity
  • Gear overdue — all rigs need a repack

Walk-in Tandems and Students

  1. Use the Quick Add Walk-in box at the top of the Loads page
  2. Enter their name and select Walk-in Tandem or Walk-in Student
  3. Click Create Walk-in
  4. Find them in the member search on the load
  5. Select their ticket, instructor, rig, and video options
  6. Click + Add
Walk-in tandems take 2 slots automatically. Outside videographers are auto-added to the load when selected.

Students and AFF

Static Line

Add students the same way as regular jumpers. Select their static line ticket type and choose an instructor. The instructor earns the credit set on that ticket type.

AFF Categories

Name your AFF ticket types exactly like this:

  • AFF Cat A through AFF Cat H
Cat A through D automatically show a secondary instructor dropdown — both instructors earn the full credit amount.

Cat E through H show only one instructor dropdown.

Load Statuses

  • Building — adding jumpers to the load
  • Boarding — jumpers are boarding the aircraft
  • In Air — plane has taken off
  • Landed — plane has landed
  • Closed — load is complete and saved to history

Click the status buttons on the load card to move through each stage. Closed loads disappear from the active board but are saved permanently in history.

Tandem Instructor Pay

Calculated automatically when a tandem is added to a load:

  • Base Pay — always earned, set in Settings
  • Personal Rig Bonus — if instructor uses their own rig
  • Inside Club Camera Bonus — if using club camera
  • Inside Personal Camera Bonus — if using own camera

All rates are configurable in Admin → Settings → Tandem Pay Rates.

Outside Video Pay

  • Base Pay — always earned for outside video
  • Club Camera Bonus — if using club camera
  • Personal Camera Bonus — if using own camera
Only members with a Videographer rating on their profile appear in the videographer dropdown. Add ratings in Admin → Members → View → Add Rating.

Student Instructor Pay

Set the Instructor Credit amount on each ticket type in Admin → Ticket Types → Edit. This amount is credited to the instructor automatically when a student is manifested.

One instructor can take multiple students on the same load and earns credit for each one. AFF Cat A through D support dual instructors who each earn the full credit.

Pilot Pay

Each pilot has their own Credit Per Load rate set on their profile in Admin → Pilots. The credit is applied automatically when a pilot is assigned to a load and reversed if they are changed.

Packing Credits

Log packing credits from Admin → Members → View → Packing Credits. Select Regular Pack or Tandem Pack — the rate is pulled from Settings automatically.

Waivers

Every regular member and student needs a current waiver to be manifested. Log waivers from Admin → Members → View → Safety Waiver. The Warnings tab shows everyone with an expired waiver.

Gear and Repacks

Reserves must be repacked every 180 days. Track repacks from Admin → Members → View → Edit on any rig. The repack due date calculates automatically.

  • Red warning — all rigs overdue, cannot manifest
  • Orange warning — mixed status, at least one current rig

Club gear is tracked separately in Admin → Club Gear.

Club Dues

Log dues payments from Admin → Members → View → Dues. The amount is deducted from their balance automatically. The Warnings tab shows all members with unpaid dues for the current season.

Credit Summary

View any member's credit summary from Admin → Members → View. Use the date range pickers to filter by period. Click Download Credit Summary to export a formatted Excel file with category breakdown and running balance.

Display Board

Click Display Board in the navigation bar to open a live read-only jumper board in your browser. Drag it to a second monitor and press F11 for full screen.

The display board updates silently every 10 seconds. Jumpers can see which load they are on without coming to the manifest desk.

You can also open it directly in any browser on the same computer:

http://localhost:5000/display

Warnings Tab

The Warnings tab is visible without logging into admin. It shows:

  • Members with expired waivers
  • Members with all rigs overdue — cannot manifest
  • Members with mixed gear status
  • Club gear due for repack within 30 days
  • Members with unpaid dues

Reports

Admin → Reports. Set a date range and click Apply. Download a formatted Excel report with 7 sheets covering monthly jumps, instructor earnings, pilot activity, gear status, aircraft stats, and dues.

Backups

LoadHog backs up your database automatically every time the app opens and closes. Backups are saved to:

Documents\LoadHog Backups

The app keeps the last 30 daily backups and 60 close backups. Manual backups can be downloaded anytime from Admin → Backup.

On OneDrive computers backups save to OneDrive\Documents\LoadHog Backups. On non-OneDrive computers they save to Documents\LoadHog Backups.

Restoring From a Backup

  1. Go to Admin → Restore Backup
  2. Click Restore next to any listed backup
  3. Or upload a backup file from anywhere on your computer
  4. Close and reopen the app after restoring
Your current database is automatically backed up before any restore so you can always undo it.

Admin Access

Click Admin in the top right and enter your PIN. Default PIN is 1234 — change it immediately in Settings.

Forgot your PIN? Press Ctrl + Alt + O anywhere in the app window to bypass the PIN and log in immediately. Write this down and keep it somewhere safe.

Common Problems

App won't open

Make sure the entire LoadHog folder was copied — not just the exe. The templates folder must be present.

Forgot admin PIN

Press Ctrl + Alt + O in the app window.

Member can't be manifested — no waiver

Log a waiver on their profile first. Admin → Members → View → Safety Waiver.

Member can't be manifested — gear overdue

All of their rigs have expired repacks. Update at least one repack date.

Instructor didn't get credit

Check that the Instructor Credit on the ticket type is not 0.00. Admin → Ticket Types → Edit.

Videographer not in dropdown

Add a Videographer rating to their member profile. Admin → Members → View → Add Rating.

Backups not in Documents

Look in C:\Users\username\Documents\LoadHog Backups — not in OneDrive Documents as they may be different folders.

Display board shows OFFLINE

Make sure the LoadHog app is still running. Reopen it and the display board will reconnect.
